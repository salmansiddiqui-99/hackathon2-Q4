# Todo Console App

Phase I: In-Memory Todo Console Application built with Python 3.13+

## Features

### Basic Level
- Add, List, Update, Delete tasks
- Mark task status (pending/in-progress/completed)

### Intermediate Level
- Priority assignment (high/medium/low)
- Tags/categories management
- Search, Filter, Sort tasks

### Advanced Level
- Recurring tasks (daily/weekly/monthly)
- Due dates with natural language input
- Check Reminders (overdue/due soon)

## Usage

```bash
# From project root
uv run todo

# Or run directly
uv run python -m src.main
```
